# Plugin catalog

This directory groups independently installable DeepSeek Harness extensions by product purpose. Source code stays under `packages/`; each `plugin.json` identifies the package sources and distribution artifact without duplicating implementation files.

| Category | Purpose |
| --- | --- |
| `collaboration` | Communication, productivity, and third-party workspace integrations |
| `files` | Attachment parsing, recognition, and media fallback processing |
| `models` | Model metadata, modality, and capability discovery |
| `platform` | Harness management and plugin lifecycle interfaces |
