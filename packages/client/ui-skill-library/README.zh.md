# @deepseek-ai/dsh-client-ui-skill-library

面向桌面壳的 SkillHub 技能市场。插件通过独立的 `技能库` 侧边栏入口（位于插件库上方）和 shell overlay 提供与插件库一致的“已安装”“审查安装”“社区发现”“操作日志”主 tab。“社区发现”映射 SkillHub 技能 endpoint，提供排序 tab、来源/场景/API Key 筛选、整行搜索框、单列结果行、容器内滚动、接近底部预加载及显式上一页/下一页控件。卡片链接到 SkillHub 公共页面并下载 SkillHub ZIP；当前不提供技能包 tab，写入本地技能目录的安装能力留给后续原生桥接实现。
